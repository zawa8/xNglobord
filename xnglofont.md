another feature of xnglobord will be that on long press on a-z keys will show their capital A-Z as 1st option. so that user can longpress 'a' key and type A and so on for other a-z keys.

also it will have setting with 2 radio boxes :

1. k+h -> kh or
2. k+h->K

if user selects 2 then in xnglobord if user press (k/g/c/z/t/d/j/q/b/s/n/r) + h key will type (K/G/C/Z/T/D/J/Q/B/S/N/R).
