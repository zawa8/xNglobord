xnglobord is same as Gboard but with 3 more features. 

1. it will show xnglo hscii font picker(on pressing some key or on pressing spxsebar for loNg). in this user will see selectbox and can select 1 font.then xnglobord(Gboard) will be in user selected font.already selected option will be xNglohindi.

2. another feature of xnglobord will be that on long press on a-z keys will show their capital A-Z as 1st option. so that user can longpress 'a' key and type A and so on for other a-z keys.

3. also it will have setting with 2 radio boxes :
    1. k+h -> kh or
    2. k+h->K
if user selects 2 then in xnglobord if user press (k/g/c/z/t/d/j/q/b/s/) + h key will type (K/G/C/Z/T/D/J/Q/B/S).

4. it will use x38idict for auto complete instead of English ASCII dictionary.

5. rest all wil be same as Gboard.
